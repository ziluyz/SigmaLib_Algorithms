# SigmaLib_Algorithms (crate `algorithms`)

Библиотека переиспользуемых численных алгоритмов для вычислительных проектов Sigma: собственные
реализации на Rust и FFI-мост к GNU Scientific Library. От `processor` и Sigma не зависит.

Общая картина — `../CLAUDE.md`. План тестов — раздел «Система тестов» в `../ROADMAP.md`.

Имя папки и имя crate различаются: в зависимых проектах
`algorithms = { path = "../SigmaLib_Algorithms" }`.

## Команды

```bash
cargo build
cargo test
cargo test -- --ignored     # тесты известных дефектов (сейчас таких нет)
```

## Тесты

Интеграционные тесты в `tests/`: `algebra.rs`, `argument_root.rs`, `gsl_bessel.rs`,
`gsl_integration.rs`. Сравнение чисел — только макросом `assert_close!(a, b, abs = …, rel = …)`
из `tests/common/mod.rs` (подключается строкой `mod common;`), допуск указывается явно.
Эталонные значения сопровождать источником. Тест с `#[ignore = "known bug: …"]` описывает
правильное поведение, которого пока нет: исправление = снять `#[ignore]`.

Требуется системный GSL: `sudo apt install libgsl-dev`. `build.rs` линкует `gsl` и `gslcblas`
напрямую (`cargo:rustc-link-lib`), без pkg-config.

## Состав

| Модуль | Содержимое |
|---|---|
| `algebra` | `find_root` (бисекция), `find_root_sequence` (ровно n последовательных корней от стартовой точки, точность 1e-7; следующий корень ищется не дальше `MAX_ROOT_GAP`·`min_root_dist` от предыдущего, иначе ошибка), `find_root_sequence_bounded` (до n корней на `[x_start, x_max]`, нехватка корней — не ошибка) |
| `algebra::argument_root` | `find_zeros_by_argument` — нули аналитической функции в прямоугольнике комплексной плоскости по принципу аргумента с адаптивным дроблением (`RectF64`, `Limits`, `Root`, `StopReason`, `EvalCache`). Как устроен — ниже |
| `gsl::errors` | `turn_off_error_handler()`, `get_error_description(status)` |
| `gsl::integration` | `qng` (функция), `Qawo` (осциллирующие интегранды: `new` → `initialize` → `integrate`, `change_parameters`/`change_limits`), `Romberg` (`new` → `initialize` → `integrate`) |
| `gsl::sfunctions::bessel` | `jn(n, x)` (`gsl_sf_bessel_Jn_e`: статус проверяется, underflow — это ноль, нечисловой результат — ошибка), `djn(n, x)` (производная через рекуррентность) |

### `find_zeros_by_argument`

- Число нулей в прямоугольнике — число оборотов `f` по его границе (`winding_pass`). Обход
  считается надёжным, только если между соседними точками и фаза, и `ln|f|` меняются не больше
  чем на `LOG_STEP_MAX`; иначе выборка удваивается (до `Limits::max_winding_refine` раз).
  Контроля одной фазы мало: кратный ноль у самого контура даёт скачок фазы, кратный 2π.
- Прямоугольник с ненулевым числом оборотов делится на четыре (`subdivide`). Деление принимается,
  если обходы всех частей надёжны и их сумма равна числу оборотов родителя. Если нет (ноль на
  линии деления или рядом) — линии сдвигаются (`SPLITS`, в восьмых долях); если не подошло ни
  одно положение, прямоугольник сообщается как есть с `StopReason::SubdivisionFailed`
  (так заканчивается кратный корень многочлена в развёрнутом виде — шум округления).
- `Root::multiplicity` — число нулей в итоговом прямоугольнике; сумма по всем `Root` равна числу
  нулей в области. `abs_tol` останавливает поиск только там, где ноль один.
- Ноль на границе исходного прямоугольника — ошибка («move the boundary»).
- Точки — на двоичной сетке исходного прямоугольника (ключи кеша значений `f`), индексы `u64`:
  отсюда ограничение `max_depth + log2(samples_per_edge0) + max_winding_refine <= 58`.

## Соглашения

- Все публичные функции возвращают `Result<_, String>`; функции-аргументы у `algebra` —
  `Fn(f64) -> Result<f64, String>`, у интеграторов GSL — `FnMut(f64) -> f64`.
- FFI: объявления `extern "C"` лежат в `gsl_signatures.rs` рядом с модулем-обёрткой; наружу
  торчат только безопасные обёртки. Замыкание передаётся в GSL через `GslFunction` +
  `trampoline` (`gsl/integration.rs`): в `params` кладётся указатель на `&mut dyn FnMut`.
- Ресурсы GSL (workspace, таблицы) оборачиваются в структуру с `Drop`; повторный `initialize`
  освобождает прежние. Если GSL не выделил ресурс (например, нулевой размер), объект остаётся
  неинициализированным и `integrate` возвращает ошибку — сигнатура `initialize` без `Result`.
- Обработчик ошибок GSL по умолчанию вызывает `abort()`. Коды возврата проверяются обёртками,
  но это работает только после `gsl::errors::turn_off_error_handler()` — вызывающий проект
  обязан вызвать его один раз в начале расчёта.
- Документация функций — doc-комментарии с разделами Arguments / Result / Errors (как в `algebra.rs`).
- Библиотека не печатает в stdout и не паникует на пользовательских данных.
- Новый алгоритм добавляется вместе с тестами: аналитический случай + граничные/ошибочные входы.

## Известные проблемы

- Паника внутри замыкания в `trampoline` раскручивается через кадры C — неопределённое поведение.
- `qawo`: ошибка округления GSL намеренно игнорируется (см. коммит `ac3c72e`).
